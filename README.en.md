# web-sdk-PP-OCRv6

Browser-first PP-OCRv6 OCR SDK scaffold. The six official ONNX assets are pinned to `1.0.0` and stored as Git LFS sources; the SDK defaults to versioned GitHub Release URLs with pinned Hugging Face provenance/fallback. Runtime, Demo, and documentation implementation is still in progress.
