# OCR 图片视口交互设计

## 背景

Demo 当前将原图和检测框绘制到同一张 canvas，但长图会受到自然尺寸和 CSS 最大尺寸的共同影响，用户无法稳定地查看局部细节。中间区域需要成为固定尺寸的图片视口，图片内容在视口内进行缩放和平移，不改变页面整体布局。

## 目标

- 中间区域只显示一张原图，检测框直接绘制在原图上。
- 默认按视口尺寸完整适配图片，图片不撑开页面。
- 支持鼠标滚轮、`+`/`-` 按钮缩放，缩放中心为鼠标位置（按钮缩放以视口中心为中心）。
- 支持“拖动查看”持续模式；按住空格临时进入拖动，松开恢复；按 `Esc` 退出持续模式。
- 移动端支持单指拖动和双指缩放。
- 平移范围限制在图片边界内，避免图片被拖出后露出不必要的空白。
- “适配窗口”恢复默认比例和位置。

## 交互状态

图片视口维护以下状态：

- `scale`：图片相对于原始尺寸的缩放比例，默认由视口和图片尺寸计算，范围限制在 `fitScale` 到 `maxScale`。
- `offset`：图片相对视口中心的平移偏移量，任何更新都经过边界钳制。
- `interactionMode`：`select` 或 `pan`，点击按钮切换；`Esc` 恢复 `select`。
- `spacePressed`：空格按下时临时允许拖动，不改变持续模式按钮状态。
- 指针/触摸会话：记录起始指针位置、起始偏移和双指初始距离/中心。

图片和检测框使用同一 canvas；canvas 外层固定 `overflow: hidden` 的视口。视口高度在桌面端使用稳定的可用高度，移动端使用固定的最小高度，避免长图改变网格行高。

## 缩放与边界

缩放以指针在视口中的坐标为锚点：先把锚点换算到图片坐标，再更新比例，最后调整偏移使同一图片点仍位于同一视口坐标。按钮缩放使用视口中心作为锚点。

平移边界按缩放后图片尺寸计算：当图片大于视口时，允许内容覆盖整个视口并将边缘限制在视口边缘；当图片小于视口时，将内容居中且偏移固定为零。缩放到适配比例时自动清零偏移。

## 移动端手势

- 单指拖动只在图片已放大或持续/临时拖动状态下生效。
- 双指 pinch 根据两指距离调整缩放，并以两指中心为锚点；同时保留中心附近的内容稳定。
- `touch-action: none` 只作用于图片视口，避免浏览器滚动手势与画布手势冲突；视口外页面仍可正常滚动。

## 无障碍与反馈

- 缩放和模式按钮提供中文/英文 aria-label 与 title。
- 当前拖动模式使用 `aria-pressed`，缩放比例显示为百分比。
- 现有 OCR 行点击仍更新选中框；点击 canvas 检测框仍更新右侧对应行。

## 测试

- fixture 页面加载后图片和 canvas 不超过视口边界。
- 适配状态下记录 `scale` 和偏移，滚轮缩放后比例变化且图片锚点保持。
- 点击拖动按钮、按空格、按 `Esc` 的模式状态符合设计。
- 拖动到极限后图片边缘不越过视口边界。
- 移动端视口无横向溢出；单指和双指事件不会改变页面滚动布局。
- 现有 OCR 框绘制和右侧行选中回归测试继续通过。
