# PP-OCRv6 0.2.0

0.2.0 新增模型缓存容量与身份查询、Worker/主线程资源配置、自定义模型预设和初始化观测，并修复取消、释放与计时问题。以上为向后兼容增量；模型版本继续为 PP-OCRv6 1.0.0。

## 新增能力

- `getModelCacheUsage(modelId?, version?)` 和 `resolveModelCacheIdentity(selection?, signal?)` 支持按实际模型身份统计与清理缓存；可选 `CacheWriter/createWriter` 让第三方缓存接入在途写入失效控制。
- `RuntimeOptions.wasmPaths` 接受绝对目录或 `{ mjs, wasm }`，配置同时传递到 Worker 和主线程；自定义模型支持 `preset`。
- `initialization`、`timings.initialization`、`timings.loadState` 和 `runtime.componentBackends` 分别记录历史初始化、当前调用冷热状态与实际执行组件后端。
- Demo 展示当前模型与整个 SDK 的缓存字节数，并区分新会话、复用会话、初始化等待和本次端到端耗时。

## 修复

- 初始化期间释放会取消模型和字典下载，等待初始化结束并释放已创建的执行器；主线程推理取消立即返回 `ABORTED`，后续调用与释放等待底层在途计算结束。
- 模型、清单和字典响应体读取期间的主动取消统一返回 `ABORTED`；真正的下载和清单错误保留原分类。修复默认 manifest URL。
- 缓存清理阻止同一 JavaScript 模块内已开始的下载迟到写回；IndexedDB 写入成功以事务提交为准。Demo 清理时取消任务、等待收尾并释放会话。
- 热运行不再重复累计模型加载耗时，空检测不执行识别，入口解码计入 OCR 总耗时；当前调用与历史初始化分项分开统计。

## 模型、来源与许可

模型使用 PaddlePaddle 官方 PP-OCRv6 medium/small/tiny 检测与识别 ONNX，共六个 FP32 文件。不可变 Hugging Face revision、大小和 SHA-256 见 [模型清单](https://github.com/chenmohan123/web-sdk-PP-OCRv6/blob/main/models/pp-ocrv6/manifest.json) 与 [来源记录](https://github.com/chenmohan123/web-sdk-PP-OCRv6/blob/main/models/pp-ocrv6/model-source.json)。SDK 与模型采用 Apache-2.0，第三方声明见 [THIRD_PARTY_NOTICES.md](https://github.com/chenmohan123/web-sdk-PP-OCRv6/blob/main/THIRD_PARTY_NOTICES.md)。

默认资产为 `small-det`（9,880,512 字节）和 `small-rec`（21,159,378 字节）。浏览器默认从固定 revision 的 Hugging Face 地址下载并校验大小与 SHA-256；GitHub Release 用于版本化模型归档。npm 包包含 ESM、Worker、类型、模型清单、三份识别字典和双语 README，不含 ONNX。

## 后端与使用边界

ONNX Runtime Web 固定为 1.27.0；默认使用 CPU WASM，可显式请求 WebGPU。显式后端不得静默替换，仅 `backend: "auto"` 且 `allowFallback: true` 时允许回退。支持 Worker 与主线程执行，结果报告实际后端。

2026-09-08 的包生命周期浏览器验证覆盖 Windows 10.0.26200、Chromium 151.0.7922.34、Intel Core i5-10400F 和 WASM。小型真实 ONNX fixture 用于验证 SDK 执行路径；六个官方 ONNX 另行完成元数据、完整性与 WASM 会话创建检查。这些证据不代表所有模型的识别质量，也不增加 GPU、移动端或微信宿主兼容承诺。更多带日期的证据见 [兼容性](https://github.com/chenmohan123/web-sdk-PP-OCRv6/blob/main/docs/zh-CN/compatibility.md)。

不支持微信原生小程序 runtime；不同标签页之间尚无缓存清理广播。OCR 顶层 `actualBackend` 代表 DET，混合后端需读取 `componentBackends`。独立示例和 CDN 入口固定为 0.1.8，其 API 范围与限制见各示例 README。
