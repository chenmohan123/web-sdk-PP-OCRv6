# web-sdk-PP-OCRv6

PP-OCRv6 browser OCR SDK scaffold. 六个官方 ONNX 资产已固定到 `1.0.0`，并以 Git LFS 保存源文件；SDK 默认从版本化 GitHub Release 地址加载，Hugging Face 固定 revision 作为 provenance/fallback。runtime、Demo 和文档仍在持续实现中。
